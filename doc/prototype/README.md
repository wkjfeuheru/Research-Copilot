# 前端原型 · 可丢弃

问题：在既定研究流程下，哪种信息层级最适合阅读简报、核查证据及处理人工介入？

当前没有既有前端路由或组件库，故使用独立 HTML 原型，同一路由通过 `variant` 参数切换三种结构；不作为正式前端技术栈选择。

启动（项目根目录）：`python doc/prototype/serve.py`

- A：<http://127.0.0.1:8765/?variant=A>，三栏研究台，保留已确认布局。
- B：<http://127.0.0.1:8765/?variant=B>，简报阅读台，阅读导航与旁注证据。
- C：<http://127.0.0.1:8765/?variant=C>，研究流程台，阶段卡片与结果检查区。

底部左右箭头或键盘左右键切换方案；输入框及弹窗中不拦截方向键。查看状态按钮显示当前相关内存状态。

## 交互范围

- 任务切换、演示状态切换、新建演示任务。
- 补资料弹窗、选择文件名或使用示例文件、模拟恢复与终止。
- 简报/过程/技能页签、引用定位及模拟原文弹窗。
- 图表切换、演示 Markdown/SVG/CSV 下载。
- 研报知识/任务经验切换、记忆停用、技能开关。
- 单一入口，三方案及响应式窄屏布局。

所有公司、财务值、研报、来源状态均为虚构示例；不调用模型、MCP 或搜索服务。不读取上传文件内容，不写数据库或本地存储。刷新重置数据，URL 只保留方案。

## 视觉方向

- A：白色资料纸、浅灰绿工作区、深绿强调；目标是同时看清结论与来源。
- B：灰蓝编辑台、衬线报告标题、更宽的正文留白；目标是连续阅读与引用旁注。
- C：深蓝导航、阶段卡片、分析与证据并列；目标是快速定位流程和需要介入的位置。
- 字体使用系统中文无衬线，B 报告标题使用系统宋体，数据采用等宽数字；无需外网字体。

## 已选择方向与本轮调整

用户已选择 B 的风格。默认使用 B；A、C 暂留作对照，不作为当前实施目标。

新建研究改为 Agent 式对话入口：<http://127.0.0.1:8765/?variant=B&view=new>。在同一消息输入区输入问题、多选技能、选择附件并发送；附件与技能随消息展示，并进入右侧研究上下文。支持继续发送补充消息及切换查看研究过程。所有回复仍为固定演示，不执行研究或文件解析。

原型代码仍为可丢弃实现；选定的视觉与交互应在正式前端重写。

## 本轮需求调整
