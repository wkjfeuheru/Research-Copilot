## 已确认决策

下表记录需求访谈的最终结果。后续用户修正优先于更早的建议，尤其是用户隔离、无自动触发和探索性交付三项。

| 决策 | 确认结果 |
| --- | --- |
| Q1 用户 | 用户本人及内部小团队；同一平台内按用户隔离 |
| Q2 价值排序 | 多场景覆盖、自主完成为主，同时支持研究资产复用 |
| Q3 市场 | A 股与行业研究，量化以日频为主 |
| Q4 业务终点 | 研究结论、数据集、模型和回测结果；不执行实盘交易 |
| Q5 agent 职责 | 采集、分析建模、撰写、回测、审核五类职责；独立调用、按需协作、可扩展 |
| Q6 投入约束 | 排期、人力、费用和容量数值暂未确定，先明确产品与架构 |
| Q7 工作组织 | 研究项目 → 多个任务/实验 → 各自产物 |
| Q8 交互 | 对话为主，配合参数和结果面板 |
| Q9 建模范围 | 基本面与因子研究优先，机器学习后续扩展 |
| Q10 回测 | 标准日频组合回测；agent 可在指定目标内提出并比较策略；自定义策略保留受控扩展 |
| Q11 自主边界 | 澄清必要输入后自主执行；改变用户指定的目标、样本范围或研究假设时询问 |
| Q12 审核 | 正式产物按类型检查，系统可自动返工；机器检查通过即可完成，人工复核按需 |
| Q13 协作范围 | 不支持多人共同编辑；资料、任务和研究资产按用户隔离，不默认团队共享 |
| Q14 编排 | 研究协调 agent + 五类业务 agent |
| Q15 复用 | 同一用户跨项目自动发现与复用，展示来源；用户之间隔离 |
| Q16 版本 | 每次正式执行独立留痕，产物版本化，支持实验比较 |
| Q17 数据输入 | 工具服务 + 用户文件导入，数据源接口可扩展 |
| Q18 数据不足 | 允许先交付带限制说明的探索结果 |
| Q19 停止条件 | 有界自主研究；达到验收要求或执行上限时停止，保留进度和尝试记录 |
| Q20 自动触发 | 不纳入定时或事件触发的研究任务 |
| Q21 对话层级 | 项目主对话协调研究；任务有独立执行上下文与详情面板 |
| Q22 部署形态 | 集中部署 Web，也支持单人本机运行；模块化单体 + 独立 worker + 沙盒 |
| Q23 代码交互 | 自然语言与参数修改；代码可查看、导出；完整在线编程环境后续扩展 |
| Q24 演进兼容 | 复用已有工具、计算、沙盒、审核；重构领域模型；旧成果只读，不承诺旧执行原地续跑 |
| Q25 整体确认 | 用户确认总体草案基本符合设想，进入设计文档整理 |

## 设计精度与待定项

产品边界、交互方式、职责和架构方向已确认。文档中的模块名称、字段、枚举、接口形状和分期编号属于据此形成的工程设计建议，实施时可在保持业务语义的前提下细化。

以下事项明确保留待定，不影响本次设计文档交付：

- 具体模型供应商、角色模型路由及费用、调用次数、运行时长、并发和存储额度。
- 首版时间、人力安排、硬件规格、账户接入的具体实现及部署地址。
- 补齐回测数据的供应商、覆盖年份与证券范围、商业数据授权方式。
- 回测计算库、具体交易规则参数、报告导出增强格式和数据保留期限。

这些事项分别在实施分期的入口或验收条件中收口。未设置运行上限不等于允许无限执行；数据供应商未选定不等于回测数据已具备。
