# 高阶估值方法 (Advanced Valuation Techniques)

## 定位

覆盖标准 DCF/Comps 无法处理的特殊场景：资本结构变化、多元化集团、新兴市场、非线性价值、金融机构。按需加载，不作为默认路由。

---

## 1. APV 调整现值法 (Adjusted Present Value)

### 何时使用（替代 WACC-DCF）

| 场景 | 原因 |
|------|------|
| 资本结构每年变化 | WACC 假设固定 D/E，逐年变化时失真 |
| LBO 退出建模 | 高杠杆逐年偿还，D/E 每年不同 |
| 项目融资 | 分期还款导致 D/E 持续下降 |
| 资本重组 | 大幅去杠杆/加杠杆 |

### 公式

```
APV = 无杠杆企业价值 + PV(税盾)
    = Σ[UFCF_t / (1 + Ru)^t] + Σ[Tax Shield_t / (1 + Rd)^t]
```

- **Ru**：无杠杆权益成本（unlevered cost of equity）
- **Tax Shield_t** = Interest_t × Tax Rate
- 税盾折现率：用税前债务成本 Rd（经典 Modigliani-Miller）

### vs WACC-DCF 对照

| 维度 | APV | WACC-DCF |
|------|-----|----------|
| D/E 稳定 | 均可 | 首选（更简洁） |
| D/E 逐年变化 | **首选** | 失真 |
| 透明度 | 分离经营价值与融资价值 | 混在一个折现率中 |
| 终值期 | 可切回 WACC 处理 | 自然处理 |

## 2. SOTP 分部估值 (Sum-of-the-Parts)

### 适用场景

- 集团各业务属于不同行业（增长/风险/倍数迥异）
- 单一倍数会系统性高估低增长分部或低估高增长分部
- 典型：Alphabet（广告+云+Waymo）、Amazon（电商+AWS+广告）、综合集团

### 五步流程

1. **业务分割**：按 10-K/年报分部信息（ASC 280）获取收入、EBITDA、资本
2. **各分部独立估值**：为每个分部选择最适合的方法和 Comps
3. **加总分部 EV**
4. **扣除母公司层面净债务**（非合并口径）
5. **施加集团折价**（如适用）

### 集团折价 (Conglomerate Discount)

| 折价范围 | 驱动因素 |
|---------|---------|
| 10-15% | 信息不透明 + 管理复杂度 |
| 15-25% | 交叉补贴弱势业务 + 代理成本 |
| 0% 或溢价 | 各分部独立表现优秀且充分披露 |

McKinsey 洞见：多数"集团折价"实为"业绩折价"——如果分部表现与同行一致，折价消失。

### 公司费用分摊

- 方法 A：按收入比例分摊至各分部
- 方法 B：将总部费用资本化为独立负债项从加总中扣除
- 方法 C：直接作为折价因子（总部成本 / 合理倍数 → 扣除额）

## 3. 国别风险溢价 (Country Risk Premium)

### Damodaran 方法（2026年最新）

```
CRP = 主权违约利差 × 股权/债券相对波动率系数
Total ERP = 成熟市场 ERP + CRP
```

- 2026年7月成熟市场 ERP 基准: **4.17%**
- 股权-债券波动率乘数: **1.55**

### 关键区域 ERP 参考

| 区域 | 总 ERP |
|------|--------|
| 北美 | 4.43% |
| 西欧 | 5.24% |
| 亚洲 | 5.80% |
| 中南美 | 8.60% |
| 非洲 | 12.59% |

### Lambda 方法（收入加权）

跨国公司按收入来源地加权计算 CRP，而非上市地：
```
Company CRP = Σ(Revenue_region_i / Total Revenue × CRP_region_i)
```

## 4. 回归估值法 (Regression-Based Valuation)

### 核心方法

对同行业 15-40 家公司做截面回归：
```
Predicted Multiple = α + β₁(Growth) + β₂(Margin) + β₃(ROE) + ...
```

### 典型模型

| 因变量 | 自变量 | 适用 |
|--------|--------|------|
| P/E | EPS Growth, Payout, Beta | 通用 |
| EV/EBITDA | Revenue Growth, EBITDA Margin | 工业/科技 |
| P/B | ROE, Growth, Risk | 银行/金融 |

### 优势 vs 局限

| 优势 | 局限 |
|------|------|
| 量化增长-质量权衡 | 牛市中嵌入高估 |
| 比简单中位数更科学 | 对异常值敏感 |
| 可溯源审计 | 依赖同行选择 |

### PEG 比率（简化版回归）

```
PEG = P/E ÷ 预期 EPS 增长率
```
- PEG = 1 为经验法则"合理"（但因利率/市场环境而变）
- 实际：更精确做法是让回归自由拟合截距和斜率

## 5. DDM 股息贴现模型 (Dividend Discount Model)

### 适用范围

- 银行/金融（标准 FCFF-DCF 失效）
- 成熟稳定分红的公用事业
- 任何 FCF 无法清晰定义的公司

### 变体

| 模型 | 公式 | 适用 |
|------|------|------|
| Gordon Growth | V = D₁/(r-g) | 成熟稳定 |
| 两阶段 | 高增长N年 + Gordon终值 | 正在扩张 |
| H-Model | 增长率从高到低线性衰减 | 过渡期 |
| 三阶段 | 高增长→过渡→稳定 | 最精确 |

## 6. 剩余收益模型 (Residual Income / Excess Return)

### 核心公式

```
RI_t = (ROE_t - Re) × Book Value_{t-1}
Price = BV₀ + Σ[RI_t / (1+Re)^t] + TV
```

### 核心洞察

- P/B > 1 ⟺ ROE > Re（创造价值）
- P/B < 1 ⟺ ROE < Re（毁灭价值）
- 对银行：ROE 12%、CoE 8% → 每 $10B 权益年创 $400M 超额价值

## 7. 实物期权 (Real Options)

### 适用场景

| 场景 | 期权类型 |
|------|---------|
| 医药管线 | 序列复合期权（各临床阶段） |
| 矿业勘探 | 延迟期权（等待高价格再开采） |
| 科技平台 | 扩张期权（新市场/新产品） |
| R&D 项目 | 放弃期权（止损退出） |

### Black-Scholes vs 二叉树

| 维度 | Black-Scholes | 二叉树 |
|------|--------------|--------|
| 适用 | 单阶段决策 | 多阶段序列决策 |
| 优势 | 解析解、简洁 | 可建模多个决策节点 |
| 医药 | 单管线快速估值 | 多期临床首选 |

### 实操简化

对多数应用：**决策树 + 概率加权情景** 比纯期权定价更实用、更透明。

## 8. Football Field 最佳实践

### 标准包含方法（3-6 条 Bar）

| 方法 | 区间驱动因素 |
|------|------------|
| DCF | WACC × 终值假设敏感性 |
| Trading Comps | 25th-75th 百分位 |
| Precedent Transactions | 含控制权溢价 |
| LBO Analysis | 入场/退出假设区间 |
| 52w Trading Range | 历史市场价格 |
| Analyst Targets | 共识范围 |

### 构建规则

1. 全部统一为同一口径（每股 或 EV）
2. 同一估值日、同一 Bridge 假设
3. 不混用 LTM/NTM
4. 标注当前股价位置
5. 识别 "Overlap Zone" = 最高置信区间

### 解读信号

| 信号 | 含义 |
|------|------|
| 紧密重叠 | 高置信度 |
| 宽分散 | 假设分歧大 |
| 先例 >> Comps | 控制权溢价显著 |
| LBO Floor < DCF | 存在战略溢价空间 |

### 何时排除某方法

- 金融机构：排除 FCFF-DCF，用 DDM/RI
- 早期亏损：排除 P/E
- 无可比交易：排除先例
- 非 LBO 候选：排除 LBO
