# 图表选择

柱状图比较离散主体，折线展示有序期间，散点检查两个有单位的变量。堆叠柱只用于可加总分项。
瀑布图表达有符号增减；估值区间图比较各方法的上下界；二维热力图展示明确坐标与逐点计算的敏感性。
K 线和成交量须来自授权行情输入，OHLC 顺序为 open、close、low、high；禁止猜造交易日或成交量。
树图使用正权重组成；桑基图需要真实 source→target 关系、正流量和 flow_basis，普通占比不属于流量。

Matplotlib 为默认静态研究图，ECharts 用于悬浮、缩放和系列切换。两者使用同一冻结数据，浏览器不得取新数或算财务结论。
ECharts 通过预装 Node SSR 与 Resvg 输出 PNG，不访问网络。配置只允许共享 chart_policy.json 的数据和样式；tooltip richText，不用 HTML/函数/外部图片。
固定尺寸 1200×720，范围 320–2400 / 240–1600；中文字体 Noto Sans CJK SC。检查长标签、负值、缺失、大数、小数、单位、图例和裁切。空数据返回缺口，不交付空白图。
每张图提供 data.json、chart.json、PNG、alt 和真实输入关联。交互状态不改变静态图、审核版本或计算结果；打印与导出使用 PNG。
