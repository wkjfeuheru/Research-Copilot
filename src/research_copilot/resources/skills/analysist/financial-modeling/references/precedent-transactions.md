# 先例交易分析 (Precedent Transaction Analysis)

## 定位

回答"历史上买家为类似公司付了多少倍"。通过已完成的 M&A 交易倍数，推导目标公司的隐含估值区间。**已包含控制权溢价**（通常比 Trading Comps 高 20-40%）。

## 核心用途

- M&A 交易定价与谈判
- 公平性意见书 (Fairness Opinion)
- 上市公司私有化估值参考
- 与 Trading Comps 形成估值区间上下界

## 标准流程

```
Step 1: 筛选可比交易
Step 2: 收集交易数据
Step 3: 计算交易倍数
Step 4: 分析控制权溢价
Step 5: 确定隐含估值范围
Step 6: 与 Trading Comps 对比
```

## Step 1: 筛选标准

| 维度 | 标准 | 说明 |
|------|------|------|
| 时间 | 最近 3-5 年 | 反映当前市场环境；>5年仅作参考 |
| 行业 | 相同 GICS/SIC 或直接竞争对手 | 最重要筛选条件 |
| 交易规模 | 目标 EV 的 0.3x-5x | 范围可略宽于 Comps |
| 地域 | 同区域或可比市场 | 跨境交易单独标注 |
| 交易类型 | 战略收购 / PE 收购 / 两者 | 分开统计或合并 |
| 完成状态 | 仅已完成 | 排除撤回/终止/未决交易 |
| 目标公司状态 | 上市 / 私有 | 上市更透明；私有需调整 |

### 筛选数量

- 初筛: 15-30 笔
- 最终列表: 8-15 笔
- 高度可比: 3-5 笔（同子行业 + 同规模 + 近期）

### 数据来源

| 来源 | 覆盖 | 说明 |
|------|------|------|
| 公司公告/8-K/Form S-4 | 上市目标 | 最权威 |
| 合并代理声明 (Merger Proxy) | 详细条款 | 含 Fairness Opinion |
| Capital IQ / Bloomberg | 全球交易 | 标准化数据 |
| PitchBook / Preqin | PE 交易 | 覆盖私有化 |

## Step 2: 收集交易数据

### 每笔交易需收集

| 字段 | 说明 |
|------|------|
| 交易日期 (Announce / Close) | 时间排序 |
| 买方名称与类型 | 战略 vs 财务买家 |
| 目标名称 | |
| 交易对价 (Equity Value) | 每股报价 × 完全稀释股份 |
| Enterprise Value | Equity + Net Debt at close |
| 支付方式 | 现金/股票/混合 |
| 目标 LTM Revenue | 交易宣布前最近12个月 |
| 目标 LTM EBITDA | 同上 |
| 目标 LTM EBIT | 同上 |
| 目标 NTM Revenue/EBITDA | 宣布时一致预期 |
| "无影响"股价 | 传闻前1天/1个月/1周 |
| 是否竞标 | 影响溢价水平 |

## Step 3: 计算交易倍数

### 核心倍数

| 倍数 | 公式 | 适用场景 |
|------|------|---------|
| EV / LTM EBITDA | 最常用 | 跨行业通用 |
| EV / LTM Revenue | 未盈利 | 科技/SaaS/早期公司 |
| EV / NTM EBITDA | 高增长 | 前瞻估值 |
| EV / LTM EBIT | 折旧扭曲时 | D&A差异大的行业 |
| P / LTM EPS | 上市对上市 | 有意义的盈利 |
| EV / Subscribers (Users) | 平台/媒体 | 用户驱动的业务 |

## Step 4: 控制权溢价分析

### 计算

```
控制权溢价 = (每股报价 / "无影响"股价) - 1
```

### "无影响"股价选择

| 基准 | 含义 | 适用 |
|------|------|------|
| 宣布前1天 | 无泄露假设 | 默认选择 |
| 宣布前1周均价 | 平滑短期波动 | 波动大时 |
| 宣布前1月均价 | 排除传闻期炒作 | 有提前泄露迹象时 |
| 52周最高价 | 保守基准 | 股价近期大跌时 |

### 溢价区间参考

| 范围 | 情境 |
|------|------|
| 10-20% | 友好协商，无竞标 |
| 20-40% | 标准竞争性流程 |
| 40-60%+ | 敌意收购 / 竞标战 / 战略必须 |

### 影响溢价的因素

| 因素 | 溢价↑ | 溢价↓ |
|------|-------|-------|
| 竞标者数量 | 多个竞标者 | 单一买家 |
| 协同预期 | 高协同潜力 | 低协同 |
| 目标态度 | 抵制/设置毒丸 | 主动寻求出售 |
| 市场环境 | 牛市/流动性充裕 | 熊市/信贷紧缩 |
| 战略价值 | 稀缺资产/不可替代 | 可替代标的多 |

## Step 5: 隐含估值

```
隐含 EV = 目标 LTM EBITDA × Precedent Tx Median EV/EBITDA
隐含 Equity = EV - Net Debt
隐含每股 = Equity / Diluted Shares
```

### 估值区间

| 口径 | Low (25th) | Mid (Median) | High (75th) |
|------|-----------|--------------|-------------|
| EV/EBITDA 隐含每股 | | | |
| EV/Revenue 隐含每股 | | | |

## Step 6: 与 Trading Comps 对比

| 维度 | Precedent Transactions | Trading Comps |
|------|----------------------|---------------|
| 估值基础 | 历史成交价格 | 当前市场交易 |
| 控制权溢价 | ✓ 已包含 | ✗ 不包含 |
| 时效性 | 历史（可能过时） | 实时 |
| 典型结果 | **更高**（+20-40%） | 更低（市场日常折价） |
| 隐含含义 | "有人愿意付这么多" | "市场认为值这么多" |
| 主要用途 | M&A 定价/Fairness Opinion | 一般股权估值 |

### 整合使用

```
估值排序（通常）:
Precedent Transactions > DCF ≈ Trading Comps + Control Premium

如果 Precedent Tx 显著高于 DCF → 可能反映当时市场过热
如果 Precedent Tx 显著低于 DCF → 可能行业处于低谷/买方有议价权
```

## 局限性与注意事项

| 局限 | 应对 |
|------|------|
| 历史交易反映过去市场环境 | 标注交易时市场状况（牛/熊/中性） |
| 样本量可能不足 | 放宽筛选条件并说明 |
| 私有交易信息不完整 | 标注 "Limited Disclosure" |
| 不同交易动机混合 | 区分战略 vs 财务买家分组统计 |
| 协同预期已嵌入价格 | 不可直接叠加额外协同 |
